# Four-Quail Coops

Interactive 3D build models of two quail coops for four birds, on two tabs. Both are one level, 4′ wide × 2′ deep, on a light 2×2 frame, with a sleeping box on one half and two front doors (mesh for the run, plywood for the box).

- **Porch coop** (`#porch`, the default tab): sits under a porch roof. Plywood back, sleeping-box end and top; hardware cloth on the run end. About 3′-10″ tall.
- **Outdoor coop** (`#outdoor`): the same design with its own shed roof (corrugated steel over a 7/16″ OSB deck), an OSB floor and pressure-treated corner posts that double as legs. About 4′-6″ tall at the front.

Open `index.html` in a browser. You can drag to rotate the model and toggle layers on screen to show the framing. Each model has its own options:
neither coop has options.
The shopping list, cut list and weight estimate are generated from the same geometry, so they update when you change an option.

`coop.html` is the same page without the document wrapper, which is the form used for publishing it as a Claude artifact.
